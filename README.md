# Paradise Nursery Shopping Cart

## Project Name
Paradise Nursery - Online Plant Shop

## Description
A React shopping cart application for Paradise Nursery, an online plant shop.
Users can browse houseplants, add them to cart, manage quantities, and checkout.

## Features
- Browse plants in 3 categories with 6 plants each
- Add to cart with live count update
- Increase, decrease, or remove cart items
- View total cost per item and overall total
- Responsive navigation bar
- Landing page with background image and Get Started button

## Technologies Used
- React.js
- Redux Toolkit
- CSS3
